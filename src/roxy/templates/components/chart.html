{#- Charts: the server-drawn sparkline and the time-series chart container (plan 14.5). What `sparkline(values)` draws a tiny trend line as inline SVG on the server: no script, prints well, and is ready on first paint. `timeseries(id, title, spec=..., src=...)` renders the container that static/js/charts.js turns into a uPlot chart with drag-to-zoom (plus zoom buttons, because dragging must never be the only way, WCAG 2.5.7), a crosshair readout of every series, legend toggles, a dashed comparison overlay and annotation markers. Why Charts must be readable without color and without a mouse (plan 14.9): every chart has a plain-language summary (the plot's accessible name), a data table alternative inside
, and a visible list of annotations. How The chart spec travels as JSON in a single-quoted `data-spec` attribute (`tojson` escapes quotes and angle brackets, so this is safe), or is fetched from `src`. Spec shape (all times are UNIX seconds): {"x": [t0, t1, ...], "series": [{"label": "Requests in", "values": [...], "color": 1, "kind": "line|area|bars", "stack": "group id or null", "compare": [...same length, optional...]}], "compare_label": "Previous period", "annotations": [{"t": t, "iso": "2026-10-07T14:02:00Z", "when": "14:02", "kind": "config|incident", "label": "cache_ttl_seconds 300 to 600", "href": "/admin/audit#..."}], "y": {"unit": "req/min", "min": 0, "format": "count|bytes|percent|ms"}, "summary": "one sentence for screen readers"} An annotation `href` must be a path on this site (format.html `local_href`); anything else shows as text. `color` is a series slot 1 to 8 (tokens --series-1..8, fixed order, never cycled).
