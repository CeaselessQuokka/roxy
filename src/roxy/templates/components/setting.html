What `setting_control(spec, value, save_url="/admin/...", meta={...}, history_url=...)` renders a self-contained form for one `SettingSpec` (roxy/config/spec.py): label, copyable key, the right input for the type (number with unit and range slider, switch, select with option descriptions, duration and size inputs that accept "90s", "15m" or "64 MiB"), default badge, risk badge, "what happens if" text, inline validation, and Save with a reason. "Reset to default" fills in the default (parity row 124); nothing is saved until Save. Why Plan principle P3: the setting's metadata is declared once in Python and every editor is generated from it, so the UI can never offer a value the server does not know. A high-risk value (a `high_risk_if` condition of the spec) needs a reason and an explicit "I understand" before it can be saved (plan 15.1), and the server checks the same rule again, so the browser is a convenience, never the guard.
