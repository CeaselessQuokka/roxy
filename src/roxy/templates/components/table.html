Every control re-asks the server through htmx: the server answers with the same macro for the new page, and htmx swaps the whole block (`outerHTML` on `#id`). The same macro serves the first page render and every fragment, so the two can never drift. How State lives in one form (`#id-state`): q, filters, and hidden page, size, sort and dir inputs.
