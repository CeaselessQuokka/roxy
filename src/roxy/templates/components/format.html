Why: one formatter for every number keeps tiles, tables and charts consistent; static/js/format.js mirrors these rules for numbers formatted in the browser. How: plain Jinja arithmetic and str.format; sizes use binary units (KiB = 1024 bytes) like the settings editor. Also `local_href(url)`: the URL when it is a path on this site ("/admin/audit#4"), else nothing. Links that come from data (table cells, chart annotations) go through it, so a value such as "https://...", "javascript:..." or "//host/..." never becomes a link; the text stays.
