How to read the workers

Every {{ term("worker", "worker") }} serving traffic. gunicorn recycles a worker once it has served {{ num(max_requests) if max_requests else "its" }} requests, so their ages differ by design. A worker whose memory climbs while the others stay flat is the one worth looking at.

All requests counts everything a worker served, this dashboard included, because that is what gunicorn counts toward recycling. Proxy requests counts only traffic aimed at the proxy. If the first climbs and the second does not, the only thing talking to the server is you: the proxy is idle, not broken.

The {{ term("leader", "leader") }} runs the scheduled jobs; a stale row is a worker that stopped or froze, and goes away once the heartbeat table is pruned.
