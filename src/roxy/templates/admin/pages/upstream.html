Words used here: an {{ term("egress") }} is the path a call to Roblox takes; a {{ term("bucket") }} is one of Roxy's own speed limits (it fills as calls go out and empties at its rate); a {{ term("cooldown") }} pauses calls after Roblox says "too many" (with a {{ term("retry-after") }} time when Roblox gives one); a {{ term("breaker") }} stops calling an endpoint that keeps failing and later lets one test call through; the {{ term("adaptive-rate", "adaptive rate") }} lowers an endpoint's speed after a 429 and raises it again slowly.

The fill gauges say "room to spare" below 70 percent, "busy" from 70 and "full" from 95, where the next call waits for a slot. Settings sit under each card ("Settings for this card"); every change is saved through the settings API and written to the audit log.
