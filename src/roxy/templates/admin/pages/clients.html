Places are usually the view you want: a Roblox game reaches Roxy from hundreds of rotating server addresses, so the same caller is one row under Places and a hundred rows under IP addresses. Use the addresses for anything that is not a game: scripts, scrapers, your own testing.

A {{ term("place") }} id is self-reported (the Roblox-Id header), so treat it as evidence rather than proof; it is still the one identifier that stays the same while a game's servers come and go, which makes it the one worth writing a rule against. Rates are requests per minute: Rate1 is the last minute, the number an incident is judged on. Place ids, endpoints and User-Agents are text callers sent; they are shown as plain text.
