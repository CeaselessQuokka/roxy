The {{ term("bot-score", "bot score") }} adds up signals that a client is a script rather than a game server: a library User-Agent, no Roblox signature, probes, refusals, a machine-regular rhythm, an unusual header order and cache-busting query strings. Each signal is between 0 and 1; the score is 100 times the weighted average, so it runs from 0 (looks like a game server) to 100 (looks like a script). No single signal proves anything, which is why they are combined; the score blocks nothing unless you set a block threshold.
