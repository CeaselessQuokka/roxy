Welcome to Roxy!

					

						

							Roxy is a free proxy for Roblox web APIs. Roblox game servers cannot call
							*.roblox.com from HttpService, so Roxy makes the call for you and returns
							Roblox's answer. It caches popular answers and shares Roblox's rate limits fairly between every game
							that uses it.
						

						

							The person who made
							Roproxy
							has a GitHub available to make your own proxy. So if
							you are looking for this option, it exists and is your safest option for using a proxy.
						

						

							Why did I make Roxy? Because
							Roproxy
							throttles about 60 seconds per request, and I wanted something a bit faster for my own projects. I
							figured if I'm going to make the proxy anyway, I may as well share it.
						

						

							Found a problem or a security issue? Please tell {{ contact_name }}. White Hats can read about
							vulnerability reporting and rewards below.
						

					

				

			


			

				

					
Quick start (30 seconds)

					

						

							Use Roxy exactly like the Roblox API: put https://roxytheproxy.com/ in front of the Roblox
							host. For example:
						

						
https://roxytheproxy.com/avatar.roblox.com/v2/avatar/users/29371917/outfits?outfitType=Avatar&page=1&itemsPerPage=100&isEditable=true

						

							That works in a browser, and from a server Script with HttpService (turn on
							Allow HTTP Requests in Game Settings, Security). Every example here is complete,
							typed Luau that passes the type checker in --!strict mode; names that are never
							assigned again are declared with const (if your Studio does not accept it yet, write
							local instead).
						

						{{ examples.get_async }}
						

							GetAsync raises an error for anything but success. To read the status code and wait as
							long as Roxy asks you to, use RequestAsync:
						

						{{ examples.request_async }}
						

							Adding &prettyprint=true (or ?prettyprint=true when there is no other
							parameter) makes the JSON easier to read in a browser. It is specific to Roxy and works for every
							request type:
						

						
https://roxytheproxy.com/avatar.roblox.com/v2/avatar/users/29371917/outfits?outfitType=Avatar&page=1&itemsPerPage=100&isEditable=true&prettyprint=true

						
More examples, including batch lookups and a reusable module with caching, are in the user guide.

General Tips (Highly Recommended Reading)

					

						

							Roxy is for public, unauthenticated Roblox web API calls only; it does not support
							requests that need you to be logged in, and it will reject any request that looks like it carries a
							Roblox .ROBLOSECURITY cookie. Never send your ROBLOSECURITY token to Roxy (or
							to any third-party proxy). More info below for why.
						

						

							It is highly encouraged to have caching on your end to make fewer requests, and also have instant
							responses. Batch endpoints that take a list of ids turn many requests into one.
						

						
If you use RequestAsync, Roblox gives you the response headers. These are the most useful ones Roxy adds:

						
    
							
  • Roxy-Requests-Left: How many more requests you have until you get throttled.
    • 
							
  • Roxy-Throttle-Reset: How many seconds until your request pool resets.
    • 
							
  • Roxy-Throttled: Whether or not you have been throttled.
    • 
							
  • Retry-After: How many seconds to wait before trying again, on 429 and 503 answers.
    • 
							
  • Roxy-Cache: Whether the answer came from Roxy's cache (HIT) or from Roblox (MISS).
    • 
							
  • Roxy-Paused: Only present when the proxy is temporarily paused for maintenance.
    • 
							
  • Roxy-Blocked: Only present when the endpoint you requested has been blocked by the admin.
    • 
							
  • Roxy-Endpoint-Limited: Only present when a per-endpoint rate limit rejected your request.
    • 
						

						
Every header is described in the guide.

					

				

			


			

				

					
POST / PATCH / PUT / DELETE Requests

					

						

							Most (if not all) POST/PATCH/PUT/DELETE endpoints on
							Roblox's API require you to be logged in. Roxy
							does not support authenticated requests, so these methods only work
							against the small number of public, unauthenticated endpoints Roblox exposes, such as batch lookups. If
							you need to write data as a specific account, you'll need to call Roblox directly with your own
							authenticated client, and unfortunately that isn't something Roxy can do for you.
						

						

							The calling convention is the same as GET, with a different Method and a JSON
							Body. This batch lookup is public, so it works through Roxy:
