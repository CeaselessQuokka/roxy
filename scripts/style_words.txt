# Banned spellings for Roxy (plan C5). Read by scripts/check_style.py and roxy/core/style_guard.py, so CI and the
# owner see the same list.
#
# [words] section: one rule per line, "<case-insensitive regular expression> <US replacement>". A pattern matches
# whole words and their inflections (-s, -es, -d, -ed, -ing, -er, -able, -al, -ful, -less, -ation and a few more;
# a pattern ending in "e" also matches with the "e" dropped before -ing, -er, -able, -ation). The square brackets
# are deliberate: the pattern for the British word does not match its own text, so this file passes its own check.
# A pattern that starts or ends with \b matches only the exact word (for example "enrolled" is fine in US English).
#
# [exceptions] section: one case-insensitive regular expression per line. Text it matches is skipped by the word
# rules (never by the dash rule): URLs, and identifiers or US words that share a stem with a banned pattern.
